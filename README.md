# Помощник Пятнашки

Telegram-бот для студентов УО «БГК им. А. Е. Ларина»: листы замен и консультаций, история расписаний, личный трекер долгов и учебные материалы.

[Открыть бота](https://t.me/pomoshnik_pyatnashki_bot) · [Развёртывание и обновление](DEPLOY.md) · [Связаться с автором: @menmamoh](https://t.me/menmamoh)

## Для студентов

- **Расписание занятий:** общие листы замен и консультаций, полученные с Google Диска или опубликованные администратором вручную.
- **История расписаний:** переход к предыдущим публикациям и возврат к актуальной. Просмотр старой версии не меняет расписание для других пользователей.
- **Трекер долгов и работ:** предметы, добавление работ, отметки о сдаче и сводка оставшихся долгов.
- **Учебные материалы:** база методичек и решений, отправка своих материалов на проверку администратору. Эти пункты находятся внутри трекера.
- **Полезное:** отправка отчёта об ошибке, фото примера заявления и чистый PDF для печати.
- **Профиль:** Telegram ID и выбранная группа, возможность изменить группу.
- **Обычные анонсы:** пункт «Уведомление» появляется при наличии непрочитанного объявления администратора.
- **Важные анонсы:** приходят отдельным сообщением и показываются вместо главного меню до нажатия «Закрыть». Закрытие сохраняется отдельно для каждого студента; звук и пуш зависят от настроек Telegram.

Доступность трекера и учебных материалов зависит от группы. Сейчас меню открывает их для ТТ-36 и групп с префиксами ХК и ВД. Для остальных групп бот предлагает отправить список предметов через «Полезное → Сообщить об ошибке»; добавление предметов требует работы администратора.

**Текст замен для своей группы** доступен после проверки и публикации администратором. Автоматическое распознавание сначала создаёт черновик: непроверенный текст студентам не показывается. Общие листы замен и консультаций также доступны как фотографии. Текст замен не заменяет основное расписание занятий.

## Первый вход и профиль

1. Открой бота в личном чате и отправь `/start`.
2. Выбери свою группу и подтверди выбор. Кнопка «Нет, выбрать другую» возвращает к списку групп.
3. Дождись решения администратора: верификация обязательна.
4. После одобрения разделы доступны через главное меню.

Изменить группу можно в «Профиль → Изменить группу». У уже подтверждённого пользователя смена группы не создаёт новую заявку на вход. Повторный выбор текущей группы ничего не меняет.

В меню команд Telegram публикуется только `/start`; основные действия доступны по кнопкам. Статус верификации хранится в SQLite. Он сохраняется при обновлении, если сохранена рабочая база — см. [инструкцию по хранению данных](DEPLOY.md#хранение-данных).

## Для администратора

- Проверка заявок на вход и присланных учебных материалов.
- Список верифицированных пользователей по группам: количество людей, имя, username при наличии и Telegram ID; пагинация и возврат к категориям.
- Режим тестирования групп для просмотра их предметов, материалов и расписания.
- Публикация общего расписания: текст, фотография или альбом с подписью.
- Ручная синхронизация листов с Google Диском.
- Просмотр истории и удаление старых версий через соответствующую кнопку.
- Публикация обычных и важных анонсов: выбор типа, предпросмотр и подтверждение. Для важных анонсов показывается число успешных и неудачных доставок.
- Отдельная очередь отчётов об ошибках: текстовый ответ пользователю с предпросмотром и история ответов. Кнопки очередей появляются при наличии заявок или отчётов.

Фоновая синхронизация запускается примерно через 15 секунд после старта и затем проверяет Google Диск каждые 30 минут с учётом времени самой проверки. Сообщение о новых скачанных листах отправляется администратору. Повторная синхронизация неизменившихся данных не создаёт новую версию истории.

## Анонсы

В админке открой «Отправить объявление всем», пришли текст или фото с подписью, выбери тип на предпросмотре и подтверди публикацию.

Обычный анонс остаётся в уведомлениях до открытия. Важный показывает само сообщение и кнопку «Закрыть», без картинки главного меню и его обычных разделов. После закрытия открывается следующий непрочитанный важный анонс или главное меню. Если отдельное сообщение не удалось доставить, важный анонс остаётся доступным при входе в меню.

[Подробности и проверки анонсов](docs/announcements.md). Старые объявления остаются обычными; сохранённые отметки чтения не сбрасываются.

## Локальный запуск

Используй Python 3.11, соответствующий Dockerfile проекта. Для отдельной установки сначала создай бота через [@BotFather](https://t.me/BotFather) и узнай числовой Telegram ID администратора.

```bash
git clone https://github.com/Menmamohh/study_debt_bot.git
cd study_debt_bot
python3.11 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Заполни `BOT_TOKEN` и `ADMIN_ID` в локальном `.env`. Не публикуй этот файл. На первом запуске необходим числовой `ADMIN_ID`; в последующих запусках код также может прочитать сохранённый ID администратора из базы.

```bash
python bot.py
```

При обычном локальном запуске база находится в `debts.db` рядом с кодом, скачанные листы — в `schedule/downloads/`. Чтобы выбрать другой каталог, задай `DB_PATH` до запуска. Описание переменных и инструкция для Bothost: [DEPLOY.md](DEPLOY.md).

## Проверка распознанных замен

После синхронизации Google Диска бот создаёт черновики текста замен по группам и датам.
Администратор получает исходные фотографии и текст с кнопками «Исправить текст»,
«Опубликовать» и «Пропустить». Повторно открыть черновики можно в панели администратора
или в отчёте ручной синхронизации: «Черновики замен».

Исправление сохраняет полный новый текст и снова показывает его для проверки.
Только «Опубликовать» открывает текст студентам соответствующей группы и отправляет
им уведомление. Пустой текст опубликовать нельзя. Если OCR не сработал, можно ввести
текст вручную. Черновики создаются для найденных на листе групп, а также для известных
групп с подтверждёнными пользователями. Консультации остаются исходными фотографиями.

Черновики и решения хранятся в таблице `schedule_reviews` рабочей SQLite-базы;
повторная синхронизация того же листа не создаёт их снова. При изменении исходных листов
для той же даты появляется новый черновик, старые неподтверждённые кнопки теряют силу.
Текст показывается только для выбранной ботом учебной даты и после проверки последнего
черновика этой группы и даты. Это именно **замены**, для полного списка занятий нужно
основное расписание. Общие фотографии листов продолжают обновляться автоматически.

Для автоматического чтения нужны Tesseract и языки `rus` и `eng` в среде запуска.
Dockerfile уже устанавливает Tesseract с русским языком. В обычном локальном Python
одного `pip install` недостаточно: Tesseract устанавливается отдельно.
