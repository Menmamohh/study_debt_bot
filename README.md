# 🎓 Telegram-бот: Трекер долгов по учёбе

Персональный Telegram-бот для студентов, который помогает держать все дедлайны, лабы, рефераты и хвосты по предметам под контролем.

---

## ⚡ Функционал
1. **Каталог предметов**:
   - Добавление любых учебных дисциплин.
   - Отображение количества долгов рядом с названием предмета (🔴 — есть долги, 🟢 — всё сдано).
2. **Интерактивные работы (Tasks)**:
   - Добавление работ в пару кликов (можно списком через запятую или с новой строки).
   - Мгновенное переключение статуса `[❌] / [✅]` нажатием прямо на инлайн-кнопку.
3. **Общая сводка («Показать все долги»)**:
   - Считает общее количество долгов и процент выполнения.
   - Визуальный прогресс-бар: `[████░░░░░░] 40%`.
   - Группировка всех активных долгов по предметам.
4. **База данных**:
   - Локальный SQLite (`debts.db`) — данные надежно сохраняются при перезапуске бота, каждый пользователь видит только свои предметы.

---

## 🚀 Быстрый запуск

### 1. Получение токена бота
1. Открой Telegram и найди официального бота **[@BotFather](https://t.me/BotFather)**.
2. Отправь команду `/newbot`.
3. Введи имя бота (например: *Мой Трекер Долгов*) и юзернейм (например: *menma_debt_tracker_bot*).
4. Скопируй выданный токен (вида `7123456789:AAH...`).

### 2. Установка зависимостей
Открой Терминал в папке проекта:
```bash
cd "/Users/menmamac/Documents/mind menma/study_debt_bot"
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 3. Запуск бота
```bash
# Передай токен напрямую:
BOT_TOKEN="твой_токен_от_BotFather" python3 bot.py

# Или создай файл .env:
cp .env.example .env
# вставь токен и Telegram ID администратора в .env и запусти:
python3 bot.py
```

Узнать Telegram ID можно командой `/my_id`. Укажи его как `ADMIN_ID` в `.env`.
Открой своего бота в Telegram и нажми `/start`!

### История расписаний

Новое расписание после ручной публикации или синхронизации с Google Диском
открывается по умолчанию. Кнопка «Предыдущее расписание» последовательно открывает
сохранённые публикации; «Актуальное расписание» возвращает к последней.
Старые версии доступны без ограничения по времени, пока администратор не удалит
их кнопкой «Удалить это старое расписание». Просмотр истории не меняет расписание
для других студентов. История и копии фотографий сохраняются после перезапуска.

При ручной публикации можно отправить альбом фотографий с подписью: бот собирает
его целиком, сохраняет и рассылает как одну публикацию. Неизменившиеся данные при
повторной синхронизации не создают новую версию. Таблица истории создаётся при
обычной инициализации базы при запуске бота.
