# Помощник Пятнашки

Telegram-бот для студентов УО «БГК им. А. Е. Ларина»: замены и консультации, история расписаний, трекер учебных долгов, методички и решения, объявления и связь с администратором.

[Открыть бота](https://t.me/pomoshnik_pyatnashki_bot) · [Запуск и BotHost](DEPLOY.md) · [Автор: @menmamoh](https://t.me/menmamoh)

Описание сверено 24 октября 2026 года с опубликованным кодом `7017da8`. Наличие функции в GitHub само по себе не подтверждает установку этой версии на BotHost.

## Для студентов

- **Расписание:** проверенные тексты замен для группы, общие фотографии листов замен и консультаций, ручные публикации администратора и расписание звонков.
- **История:** предыдущие публикации и возврат к актуальной; просмотр истории не меняет расписание других студентов.
- **Трекер долгов и работ:** предметы, работы, отметки о сдаче и сводка оставшихся долгов.
- **Методички и решения:** просмотр материалов и отправка своих на проверку. Раздел находится внутри трекера.
- **Полезное:** отчёт об ошибке с возможностью продолжить переписку с администратором, пример заявления и PDF для печати.
- **Профиль:** Telegram ID, выбранная группа и её изменение.
- **Уведомления:** обычные объявления в меню, важные объявления отдельным сообщением и на экране до нажатия «Закрыть», сообщения выбранной группе.

Трекер и материалы доступны для ТТ-36 и групп с префиксами ХК и ВД. Для остальных групп бот предлагает прислать список предметов через «Полезное → Сообщить об ошибке»; добавление требует работы администратора.

Текст замен публикуется только после проверки администратором. Это изменения к основному расписанию: отсутствие строки не означает отсутствие занятий. Консультации доступны исходными фотографиями. Если текста на выбранную учебную дату нет, бот может показать ближайшие будущие опубликованные замены с явной датой.

## Первый вход

1. Открой личный чат с ботом и отправь `/start`.
2. Выбери группу и подтверди выбор.
3. Дождись одобрения администратора.
4. Открывай разделы кнопками главного меню.

Группу можно изменить в профиле. Подтверждённому пользователю повторная заявка на вход не нужна. Статус подтверждения сохраняется в SQLite и переживает обновления при сохранении рабочей базы.

В меню команд Telegram публикуется `/start`. В коде также предусмотрены `/schedule`, `/bells` и `/zvonki`, `/cancel`; административная панель открывается через `/admin` в личном чате администратора.

## Для администратора

| Раздел | Возможности |
| --- | --- |
| Студенты | Заявки на вход, подтверждённые студенты по группам |
| Расписание | Синхронизация Google Диска, ручной запрос и проверка черновиков, остановка распознавания, публикации и история по группам |
| Уведомления | Текст выбранной группе; обычное или важное объявление всем с предпросмотром |
| Материалы | Проверка присланных материалов и управление базой знаний |
| Обращения | Отчёты об ошибках и переписка со студентом, включая фото |
| Проверки | Просмотр интерфейса групп и пробное распознавание |
| Статистика | Активные студенты и открытия разделов за 7 или 30 дней, разбивка по группам |

Ручное расписание можно отправить текстом, фото или альбомом. На предпросмотре администратор отмечает группы; «Все группы» включается отдельно. Перед публикацией видны содержимое и число получателей. Отмена, повторные и устаревшие подтверждения не запускают новую рассылку.

Очистка расписания и удаление старой версии требуют отдельного подтверждения в боте. Удаление данных — действие администратора, а не часть обычного обновления.

## Как обновляются замены

1. Фоновая синхронизация Google Диска начинается примерно через 15 секунд после запуска, затем повторяется через 30 минут после завершения предыдущей проверки. Ручная доступна в админке.
2. Синхронизация загружает общие листы и доставляет уведомления о новых файлах. **Gemini при этом не вызывается.**
3. Администратор нажимает «Расписание → Запросить черновики». Запрос использует уже скачанные актуальные листы.
4. При заданном `GEMINI_API_KEY` используется Gemini, без него — Tesseract. Успешные страницы и готовые результаты Gemini сохраняются в SQLite. Временные ошибки повторяются; распознавание можно остановить.
5. Администратор сверяет текст с фото, исправляет при необходимости, затем публикует или пропускает. Непроверенный текст студентам не показывается.

Многостраничные листы обрабатываются по страницам с дополнительным запросом контекста при неоднозначностях. Недоступная известная страница или незавершённая обработка не должны давать готовый неполный черновик. Выход с экрана не возвращает администратора в очередь после завершения запроса: готовые черновики открываются отдельно.

## Локальный запуск

Среда проекта — Python 3.11, aiogram 3 и SQLite. Для своей установки нужны токен от [@BotFather](https://t.me/BotFather) и числовой Telegram ID администратора.

### Windows PowerShell

```powershell
git clone https://github.com/Menmamohh/study_debt_bot.git
Set-Location study_debt_bot
py -3.11 -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
# Заполни BOT_TOKEN и ADMIN_ID в .env.
python bot.py
```

### Linux и macOS

```bash
git clone https://github.com/Menmamohh/study_debt_bot.git
cd study_debt_bot
python3.11 -m venv venv
source venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
# Заполни BOT_TOKEN и ADMIN_ID в .env.
python bot.py
```

Для Tesseract нужны отдельная установка программы и языки `rus` и `eng`; одного pip недостаточно. Dockerfile устанавливает OCR и русский язык. Для Gemini добавь собственный ключ в окружение; действительность ключа и доступность выбранной модели проверяются отдельно.

Без `DB_PATH` база находится в `debts.db` рядом с кодом, листы и история — в `schedule/downloads/`. На сервере требуется постоянное хранение базы и файлов: [полная инструкция](DEPLOY.md).

| Файл | Назначение |
| --- | --- |
| `bot.py` | Telegram, меню, права, публикации, фоновые задачи и управление экранами |
| `keyboards.py` | Кнопки, разделы админки и пагинация |

| `gemini_schedule.py` | Совместимый экспорт функций Gemini |
| `assets/` | Изображения интерфейса и образец заявления |
| `tests/` | Проверки с временными данными и подменой Telegram API |
