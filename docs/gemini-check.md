# Пробная проверка Gemini

В BotHost задана переменная `GEMINI_API_KEY`. Ключ не хранится в репозитории.
Администратор открывает «Проверить распознавание расписания» и выбирает группу.
Сервер отправляет полные сохранённые фото последних замен в Gemini одним запросом.
Результат помечен «Проверка Gemini», не создаёт черновик и не публикуется студентам.
Автоматические черновики пока используют прежний OCR до оценки качества эксперимента.

Модель по умолчанию: `gemini-3.8-flash`. Её можно изменить через `GEMINI_MODEL`.
Сомнительные поля отмечаются для сверки. Исходные фото прикладываются администратору.
Ошибка ключа, доступа, квоты или неполный ответ показывается отдельно; скрытого перехода на Tesseract нет.

Реализация включена в `schedule_review.py`, который копирует сборщик BotHost.
`gemini_schedule.py` экспортирует те же функции для совместимости.

Тесты проверяют формат уроков, структуру ответа, передачу фото и безопасную обработку ошибок.
Настоящее качество Gemini проверяется пользователем в Telegram после обновления сервера.
