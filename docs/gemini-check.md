# Настройка и проверка Gemini

Инструкция сверена с кодом GitHub `7017da8` 24 октября 2026 года. Наличие ключа и установка версии на BotHost требуют отдельного подтверждения.

## Настройка

- `GEMINI_API_KEY` — собственный ключ в окружении сервера или локальном .env; в репозиторий он не добавляется.
- `GEMINI_MODEL` — необязательное имя модели. В коде значение по умолчанию `gemini-3.8-flash`; доступность этой модели для конкретного ключа документацией не подтверждается.
- Реализация находится в `schedule_review.py`, совместимые функции экспортирует `gemini_schedule.py`, запросы выполняет отдельный процесс `gemini_worker.py`.

## Пробная проверка

1. Открой личный чат администратора: «Админка → Проверки → Проверка распознавания».
2. Выбери группу.
3. Бот проверит доступ к настроенной модели без фото, затем отправит сохранённые фото выбранных замен в Gemini.
4. Сверь текст с исходниками. Результат помечен «Проверка Gemini»; он не публикуется студентам и не создаёт черновик.

Нажатие «Остановить распознавание» прерывает процесс. Выход с экрана предотвращает позднее открытие результата поверх нового раздела.

## Рабочие черновики

Загрузка с Google Диска обновляет фотографии, но не вызывает Gemini. Запусти «Расписание → Запросить черновики» отдельно. Успешные страницы и готовые документы сохраняются в SQLite. Система обрабатывает страницы и при необходимости запрашивает контекст группы или всего документа; черновик не считается готовым до завершения обработки известных страниц.

Проверь очередь «Черновики замен», исправь текст при необходимости и отдельно подтверди публикацию. Только после публикации текст становится доступен студентам.

## Ошибки и ожидание

Проверка доступа без фото имеет сетевое ожидание 20 секунд. Для распознавания ограничение ожидания снято. Временные сетевые ошибки и HTTP 500/502/503/504 повторяются до четырёх попыток с паузами 2, 4 и 8 секунд.

Ошибки ключа, доступа, квоты, сертификата и неполный ответ показываются администратору. Ключ, доступ или квоту исправляют перед повторным ручным запросом. При ошибке настроенного Gemini скрытого перехода на Tesseract нет; без ключа подготовка черновиков использует Tesseract.

Диагностика содержит модель, количество и размеры изображений, размер запроса, длительность и исход попытки. Ключи, URL запросов, пути к фото, фамилии и текст расписания в неё не записываются.

Автоматические тесты используют подмену внешних сервисов. Реальное качество распознавания и работу в Telegram проверяет владелец бота после обновления сервера.
