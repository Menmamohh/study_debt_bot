# Статистика использования бота

В личном чате администратора открой **Админка → Статистика**.

## Главный экран

- Пользовались ботом: число уникальных активных подтверждённых студентов и общее число подтверждённых пользователей.
- Открытий разделов: сумма зарегистрированных открытий за выбранный период.
- Охват: доля активных среди подтверждённых пользователей, округлённая до целого процента.
- Пять разделов в порядке популярности: расписание, мои работы, материалы, полезное, профиль. Разделы без открытий видны с нулём.
- Периоды: **Сегодня** (с полуночи по Минску), **7 дней** и **30 дней** (скользящие периоды до текущего момента). Время показывается по Минску.

Действия администратора не записываются и не увеличивают активность. Об этом есть пояснение на главном экране.

## Подробности

**По людям:** каждый активный студент показан один раз: имя, @username или Telegram ID, текущая учебная группа, число открытий и последняя активность. Список упорядочен по числу открытий, затем по последней активности. Кнопка человека открывает его историю. По восемь человек на странице.

**История человека:** только события выбранного студента за выбранный период, по восемь событий на странице. Видны раздел, группа на момент события, дата и время. «К людям» возвращает на исходную страницу списка. Можно переключать периоды, обновлять данные и возвращаться к сводке.

**По группам:** уникальные активные студенты в каждой группе, страницы по восемь групп. Если студент менял группу за период, он может присутствовать в нескольких строках; сумма по группам тогда может превышать общее число активных.

**Последние действия:** хронологический список всех сохранённых открытий от новых к старым, с именем, @username или ID, группой и временем. Фильтры по пяти разделам и страницы по восемь событий. Старые кнопки «Кто это делал» продолжают открывать этот журнал.

## Данные и доступ

Существующие события и счётчики сохраняются, новые таблицы и миграции не требуются. Экраны только читают `usage_events` и карточки пользователей. Показываются действия пользователей, которые сейчас подтверждены. Имя и username берутся из сохранённой карточки пользователя, группа события и время — из самой записи.

До начала учёта действия не восстанавливаются. Открытие раздела не подтверждает прочтение содержимого или скачивание файла.

Статистика доступна только администратору в личном чате. Просмотр не отправляет сообщений студентам и не меняет данные.
