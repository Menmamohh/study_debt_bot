# Админка: первый этап

Статус: подготовлено к публикации в GitHub. Добавлены разделы админки и уведомления выбранной группе. Установка этой версии на BotHost пока не подтверждена.

## Главное меню

Открыть командой `/admin` в личном чате администратора или кнопкой админ-панели в главном меню.

```text
Админка

Требуют внимания:
Заявки студентов: 0
Материалы на проверке: 0
Открытые обращения: 0

[ 👥 Студенты ]       [ 📅 Расписание ]
[ 📢 Уведомления ]    [ 📚 Материалы ]
[ 💬 Обращения ]
[ 🛠 Проверки ]
[ Обновить ]          [ Главное меню ]
```

Числа — пример. Фактические счётчики берутся из базы. Все шесть разделов видны и при пустых очередях.

| Раздел | Доступные действия |
| --- | --- |
| Студенты | Заявки на вход; подтверждённые студенты по группам |
| Расписание | Обновление с Google Диска; черновики замен; расписание по группам; публикация для всех |
| Уведомления | Существующие обычные и важные объявления всем |
| Материалы | Очередь проверки; база знаний |
| Обращения | Отчёты об ошибках и существующая переписка |
| Проверки | Просмотр групп; проверка распознавания |

## Навигация

Вложенные административные экраны получили возвраты в свой раздел и админку. Существующие кнопки карточек, пагинации и действий сохранены. История, редактирование и очистка расписания доступны после выбора группы. Раздел «Проверки» сохраняет оба инструмента проверки.

Переход в административный раздел отменяет незавершённый ввод. Права администратора и личный чат дополнительно проверяются общим обработчиком административных нажатий. Неизвестные административные кнопки предлагают заново открыть `/admin`.

Очистка расписания и удаление старой версии теперь требуют отдельного подтверждения с указанием группы (и номера старой версии). Подтверждение одноразовое; отмена, новый сценарий или изменение выбранного расписания делают его недействительным. Существующие подтверждения удаления материалов сохранены. Реальные удаления и рассылки при разработке не выполнялись.

## Уведомления выбранной группе

В разделе уведомлений можно выбрать группу с подтверждёнными студентами, ввести текст и проверить предпросмотр с числом получателей. Отправка ограничена выбранной группой; подтверждение одноразовое, ошибки отдельных получателей не останавливают остальных.

Проверка перед публикацией: 139 тестов, 131 прошёл, 4 failures и 4 errors. Сравнение с актуальной версией GitHub записано в журнал обновления Obsidian. Новые проверки находятся в `tests/test_group_notifications.py`. Реальные сообщения при проверках не отправлялись.


## Публикация расписания выбранным группам

В разделе «Расписание» нажмите «Опубликовать расписание» и загрузите текст, фото или альбом.
На экране предпросмотра отметьте нужные группы. «Все группы» включается только отдельным нажатием.
Перед публикацией видны текст, число фотографий и количество одобренных получателей без администратора.
Если получателей нет, публикация недоступна. Фото дополнительно показываются администратору до подтверждения.

Кнопка «Опубликовать» сохраняет расписание только выбранным группам и отправляет им уведомления.
«Все группы» сохраняет общую публикацию ALL. Старые версии и альбомы сохраняются существующим механизмом истории.
Отмена и выход в админку отменяют черновик; старые кнопки и повторное подтверждение не запускают рассылку.
Если содержимое для группы уже опубликовано, повторная отправка этой группе не выполняется.
Группы отмечаются администратором вручную: содержимое фотографий автоматически не определяет получателей.
