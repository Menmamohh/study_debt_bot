# Описания бота для Telegram

Тексты для «Помощника Пятнашки» (@pomoshnik_pyatnashki_bot), актуализированы 24 октября 2026 года. Подготовлены в GitHub; профиль Telegram этим обновлением не меняется.

## Краткое описание профиля

```text
Помощник Пятнашки: замены, консультации, учебные долги и материалы. Связь: @menmamoh
```

## Полное описание

```text
Помощник Пятнашки — бот для студентов БГК им. А. Е. Ларина.

Смотри замены и консультации, историю публикаций и расписание звонков. В доступных для твоей группы разделах отмечай учебные долги и находи методички и решения.

Получай объявления, сообщай об ошибках и переписывайся с администратором. В «Полезном» есть пример заявления и PDF для печати.

Для входа отправь /start, выбери группу и дождись одобрения администратора. Группу можно изменить в профиле.

Контакт: @menmamoh
```

Текст замен доступен после проверки администратором и дополняет основное расписание. Трекер и материалы доступны не всем группам; условия перечислены в [README](../README.md).
