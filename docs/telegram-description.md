# Описания бота для Telegram

Готовые тексты для «Помощника Пятнашки» (@pomoshnik_pyatnashki_bot). В Telegram не опубликованы: изменение профиля выполняется только по отдельному указанию.

## Краткое описание профиля

```text
Помощник Пятнашки: листы замен, история расписаний и учебные материалы. Контакт: @menmamoh
```

## Полное описание

```text
Помощник Пятнашки — бот для студентов БГК им. А. Е. Ларина.

Смотри общие листы замен и консультаций, открывай предыдущие расписания. В доступных для твоей группы разделах отмечай учебные долги и находи методички и решения.

В «Полезном» есть пример заявления, PDF для печати и отправка отчёта об ошибке. Группу можно изменить в профиле.

Для входа отправь /start, выбери группу и дождись одобрения администратора.

Контакт: @menmamoh
```

По [Telegram Bot API](https://core.telegram.org/bots/api#setmyshortdescription), краткое описание допускает до 120 символов; [полное описание](https://core.telegram.org/bots/api#setmydescription) — до 512. Ограничения проверены 20.10.2026. Для подсчёта длины используй только содержимое соответствующего блока, без ограждений Markdown.
